# Источники

Источники используются для правил технического письма и настройки инструментов.
Дата обращения: 30 октября 2026 года.

- [Google developer documentation style guide](https://developers.google.com/style/highlights)
  — ясные формулировки, структура и оформление технических текстов.
- [MkDocs Configuration](https://www.mkdocs.org/user-guide/configuration/)
  — конфигурация сайта, навигация и проверки ссылок.
- [MkDocs Deploying your docs](https://www.mkdocs.org/user-guide/deploying-your-docs/)
  — способы публикации документации.
- [markdownlint-cli2](https://github.com/DavidAnson/markdownlint-cli2)
  — конфигурация линтера Markdown.
- [GitHub Pages custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)
  — сборка и публикация с GitHub Actions.
- [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/)
  — формат сообщений коммитов.
