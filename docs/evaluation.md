# Проверка качества стайлгайда

Для апробации составлены [инструкция U01](examples/user-guide.md)
и [протокол T01](examples/test-protocol.md). Проверка оценивает документы,
а не качество отсутствующей реализации распознавания.

## Выявленные проблемы и уточнения

| Проблема при подготовке | Уточнение правила | Результат в примере |
| --- | --- | --- |
| Названия кнопок могли восприниматься как факты о готовом продукте | G02 требует версии или отметки об учебном примере | В U01 обозначен учебный макет |
| Не было условия включения пробелов в CER | Q04 требует фиксировать нормализацию | В T01 указаны пробелы, регистр и переносы |
| Завершение обработки смешивалось с проверкой текста | D04 требует сверки с оригиналом | В U01 добавлены сверка и исправление |
| Экспорт не имел проверяемого результата | D05 требует проверки сохранённого файла | В U01 есть открытие и сравнение файла |
| Ожидаемый расчёт можно спутать с испытанием модели | Q02 разделяет ожидаемое и фактическое | T01 обозначен как расчётный пример |

## Проверка по критериям

| Критерий | U01 | T01 |
| --- | --- | --- |
| Назначение и область применения | Указаны | Указаны |
| Предварительные условия или исходные данные | Указаны | Указаны |
| Последовательность действий | 8 шагов | 5 шагов |
| Проверяемый ожидаемый результат | Содержимое файла | Значения метрик |
| Единая терминология | Соблюдена | Соблюдена |
| Неподтверждённые свойства отделены от фактов | Учебный макет обозначен | Расчётный режим обозначен |

## Оценка и ограничения

По шести применимым критериям оба документа проходят содержательную
самопроверку. Правила покрывают путь от входных данных до проверки результата
и устраняют неоднозначность расчёта метрик. Идентификаторы правил позволяют
ссылаться на конкретное требование при ревью.

Выборка из двух документов не доказывает полноту стайлгайда для всего продукта.
Не проверены документация API, реальный интерфейс и удобство для независимого
читателя. Следующая проверка должна включать рецензента и воспроизведение
инструкции на реализованной версии системы. Автоматические проверки
дополняют эту оценку, но не заменяют её.
