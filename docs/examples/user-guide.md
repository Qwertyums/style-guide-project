# Распознавание и сохранение рукописного текста

Инструкция показывает путь от изображения рукописи до сохранённого текста.
Область применения: учебный макет системы, сценарий U01, редакция 1.
Названия кнопок определены для этого макета и должны быть сверены
с интерфейсом перед применением к реализованному продукту.

## Предварительные условия

- Подготовлено читаемое изображение рукописи без личных данных.
- Страница расположена прямо; строки не обрезаны и не закрыты бликами.
- Учебный макет предусматривает загрузку изображения, запуск распознавания,
  редактирование результата и экспорт текстового файла `result.txt`.
- Допустимый формат входного изображения и его размер необходимо проверить
  по спецификации реализации; данный сценарий не устанавливает эти лимиты.

## Порядок действий

1. Нажмите **Загрузить изображение**.
2. Выберите подготовленный файл. В области просмотра появится изображение.
3. Проверьте, что видны все строки нужной страницы.
4. Нажмите **Распознать**. Дождитесь появления текста в области результата.
5. Сверьте распознанный текст с изображением, включая цифры и пунктуацию.
6. Исправьте обнаруженные ошибки в области результата.
7. Нажмите **Экспортировать** и сохраните текст как `result.txt`.
8. Откройте сохранённый файл и сравните его содержимое с исправленным текстом.

## Ожидаемый результат

Файл `result.txt` содержит проверенный и исправленный текст. Сам факт
завершения распознавания не гарантирует правильность всех символов.

## Возможные проблемы

Если часть текста отсутствует, проверьте, не обрезаны ли строки на изображении.
Сделайте новый снимок при размытости или бликах и повторите загрузку.
Если файл не принимается, сравните его параметры с ограничениями реализации.
При сообщении об ошибке обработки зафиксируйте точный текст сообщения.
Порядок описания таких случаев задан в [разделе об ошибках](../guide/errors.md).
