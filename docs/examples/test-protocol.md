# Проверка расчёта ошибок распознавания

Протокол T01 проверяет воспроизводимость описания метрик и расчёт на заданной
паре строк. Это расчётный учебный пример, а не испытание работающей модели.
Версии приложения, модели и аппаратное окружение неприменимы.

## Исходные данные и условия

Эталонная расшифровка: `мама мыла раму`.
Заданный распознанный текст: `мама мыла рамы`.
Строки составлены специально для примера, персональных данных нет.

Регистр и пунктуацию сохраняют. Пробелы учитывают при подсчёте символов.
Перенос строки в конце не входит в данные. Слова разделяют по пробелу.
Для этой пары не выполняют дополнительную нормализацию.

## Шаги и ожидаемый результат

1. Подсчитайте символы эталона, включая два пробела: ожидается 13.
2. Найдите минимальное число символьных изменений: ожидается одна замена.
3. Разделите число ошибок на 13 и умножьте на 100: ожидается 7,69 процента.
4. Разбейте строки на слова: ожидается три слова в каждой строке.
5. Найдите число изменений слов: ожидается одна замена из трёх, 33,33 процента.

Критерий прохождения: рассчитанные числители и знаменатели совпадают
с ожидаемыми; проценты округлены до двух знаков после запятой.

## Фактический результат расчёта

| Показатель | Замены | Удаления | Вставки | Длина эталона | Результат |
| --- | --- | --- | --- | --- | --- |
| CER | 1 | 0 | 0 | 13 символов | 7,69 % |
| WER | 1 | 0 | 0 | 3 слова | 33,33 % |

CER — Character Error Rate, доля ошибок на уровне символов.
WER — Word Error Rate, доля ошибок на уровне слов.
В последнем слове заменён символ «у» на «ы»; остальные символы совпадают.
Ненулевое различие требует хотя бы одного изменения, одной замены достаточно.

## Вывод

Критерий расчётного примера выполнен. Описание позволяет повторить вычисления.
Этот результат не устанавливает точность системы на реальных рукописях.
Правила расчёта определены в [разделе о тестировании](../guide/testing.md).
