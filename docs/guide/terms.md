# Терминология и сокращения

T01. Для одного понятия используйте один термин из словаря. Словарь
расширяют через PR до распространения нового термина по документации.
Цитаты интерфейса воспроизводят точно, даже если требуется отдельная правка UI.

| Термин | Значение и применение |
| --- | --- |
| Пользователь | Человек, который работает с системой; не «юзер» |
| Изображение рукописи | Входное изображение с рукописным текстом |
| Распознавание | Преобразование изображения текста в последовательность символов |
| Распознанный текст | Результат модели до пользовательской сверки |
| Исправленный текст | Результат, отредактированный пользователем |
| Экспорт | Сохранение результата в поддерживаемый формат |
| Модель распознавания | Компонент, вычисляющий текст по изображению |
| Эталонная расшифровка | Проверенный текст для сравнения с результатом |

T02. При первом употреблении на самостоятельной странице расшифруйте
сокращение; далее используйте его последовательно.

| Сокращение | Расшифровка и смысл |
| --- | --- |
| OCR | Optical Character Recognition, оптическое распознавание символов |
| HTR | Handwritten Text Recognition, распознавание рукописного текста |
| API | Application Programming Interface, программный интерфейс приложения |
| CER | Character Error Rate, доля ошибок на уровне символов |
| WER | Word Error Rate, доля ошибок на уровне слов |

T03. Для задачи рукописного текста предпочтителен термин HTR. OCR нельзя
использовать как обещание поддержки любого почерка. Идентификаторы API,
имена файлов и названия библиотек не переводят.
