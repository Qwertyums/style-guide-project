# Язык и стиль

## Формулировки

L01. Пишите по-русски, нейтрально и конкретно. Используйте активный залог:
«Система показывает распознанный текст». Убирайте «осуществляется выполнение»,
«очевидно», «просто» и оценочные обещания без измерений.

L02. В инструкции обращайтесь к читателю в повелительном наклонении:
«Выберите файл», «Проверьте текст». Один нумерованный шаг должен описывать
одно основное действие; ожидаемый отклик можно указать в том же шаге.

L03. Условие ставьте перед действием: «Если текст наклонён, выровняйте
изображение перед загрузкой». Не заменяйте конкретные условия словами
«при необходимости» без объяснения, когда необходимость возникает.

L04. Различайте возможность и обязательность: «можно» — доступный вариант,
«должен» — требование. Не используйте «быстро» и «высокая точность» без
значений, условий и метода измерения.

## Примеры исправления

| Неудачная формулировка | Предпочтительная формулировка |
| --- | --- |
| Юзер просто заливает фотку | Выберите изображение рукописи |
| Далее производится запуск распознавания | Нажмите **Распознать** |
| Все символы распознаются правильно | Сверьте распознанный текст с оригиналом |
| При ошибке повторите | Если изображение размыто, сделайте новый снимок |

Названия элементов интерфейса в примерах относятся к учебному макету.
