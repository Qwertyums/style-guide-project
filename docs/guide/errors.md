# Ошибки и ограничения

E01. Описание проблемы должно содержать симптом, возможную причину,
действие пользователя и проверяемый результат. Причину, которая не
подтверждена диагностикой, называйте возможной, а не установленной.

| Категория | Симптом | Действие |
| --- | --- | --- |
| Входные данные | Файл не принят | Сверить формат и размер с ограничениями версии |
| Качество изображения | Пропущены или заменены символы | Проверить резкость, ориентацию и полноту снимка |
| Выполнение | Обработка завершилась сообщением об ошибке | Зафиксировать сообщение и следовать инструкции для него |
| Экспорт | Файл отсутствует или не открывается | Проверить путь сохранения и повторить экспорт |

E02. Сообщения и коды ошибок воспроизводят точно по продукту. Нельзя
придумывать числовой код и выдавать его за существующий. При обращении
в поддержку указывают версию и шаги воспроизведения; рукопись с личными
данными прикладывают только после удаления таких данных и проверки разрешения.

E03. Ограничения описывают отдельно от сбоев: перечень языков, виды почерка,
таблицы, формулы и повреждённые изображения. Отсутствие сведений не означает
поддержку. Для учебного макета неподтверждённые возможности явно исключают
из обещаний документации.
